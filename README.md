# Saurabh Thakre · Product Portfolio

Live website: https://saurabhthakre.github.io/

A static product management portfolio featuring AI Agent Governance Console, Planzo, Amul, selected 2026 prototypes, professional recognition, experience and education.

Built with HTML, CSS and JavaScript, local image assets and system fonts. Includes accessible project galleries, expandable timelines, image viewers and motion that respects reduced-motion preferences.

GitHub Pages publishes the root directory of the `master` branch. Website files are at the repository root; images are under `assets/`. `.nojekyll` serves the site without a Jekyll build.
